## Known baseline issues carried forward

- Configuration, engine, application, and template state are constructed at
  import time and implicitly load the checkout `.env`.
- The default SQLite keyword path scans and substring-scores every chunk; it is
  not the L1 FTS5 implementation.
- Existing migrations represent the hosted monolithic schema and are not the
  new corpus/state schema histories.
- Raw retrieval/answer logging and account-based authentication do not match
  the local privacy/session contract.
- The core dependency set still includes PostgreSQL and S3 dependencies.

These are implementation inputs for A02 onward, not reasons to weaken the
feature specification.
